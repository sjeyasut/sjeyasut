# Hi, I'm Sarujan 👋

I'm a fourth-year **Mechatronics & AI Systems Engineering** student at Western University

I enjoy working on projects where I can take an idea, figure out how it should work, and turn it into something I can actually build and test. I love seeing projects online and figuring out how they work or how I would have done it.

### 🔧 What I'm Working On

* **Multi-Linkage Robot Arm** — A personal robotics project I'm planning to develop in stages. I'll start with a basic two-arm claw robot, then keep adding new capabilities as I learn more and build my toolbox.

### 🚀 Projects I've Enjoyed


* **Wiggles (Item Retrieval and Sorting Robot)** - Designed a ESP-32 based rover that was missioned to collect and sort erasers by color. I developed the collecting and lifting mechanism by taking inspiration from a scissor lift.
* **The Water Wheeler (Accessible Garden Watering Prototype)** — Designed and prototyped a watering system for elderly and physically impaired users. I really enjoyed the hands-on side of this project, especially iterating on the design based on feedback and seeing an idea become a working prototype.
* **NewsStream (News Retrieval & Analysis Tool)** — A Python project that retrieves and filters news using APIs. I liked the challenge of connecting different pieces of software and making the results useful to someone.
* **Study Buddy Finder** — A database project where we designed a system to match students with study partners. It was a good reminder that I enjoy the problem-solving side of software, not just writing code.
